# Connect 4 – Part 2: AI + Data Science

This package extends the supplied Part 1 engine. See `connect4/README.md` for full usage.

## Quick start

```bash
python -m pip install -r requirements.txt
python -m connect4.analytics.benchmark connect4_ai_benchmark_dataset.csv --depth 4 --output benchmark_results.csv
python -m connect4.analytics.analyze benchmark_results.csv --output-dir analysis_output
python -m unittest discover -s connect4/tests -v
```

The included `benchmark_results.csv` and `analysis_output/` were generated by actual local runs of both search algorithms against the 30 supplied board positions at depth 4. Rerun the command on your machine to obtain timings for your hardware/runtime.
